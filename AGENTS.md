# AGENTS.md

Instructions for AI coding agents working on this repository.

## Git workflow

- **Commit directly to `main` and push. Do not create branches or pull requests.**
- Before committing, make sure the project builds (`npm run build`) and that `npx tsc --noEmit` reports no new errors.
- Commit only files related to the task; don't include unrelated local changes.
- Write clear commit messages: a short summary line, then a body explaining what changed and why.
